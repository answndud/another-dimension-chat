# Another Dimension UI 디자인 기준

## 방향

Another Dimension은 일반 소비자용 메신저가 아니라, 사용자가 보안 결정을 확인하며
암호화된 1:1 통신을 수행하는 로컬 보안 작업공간이다. 따라서 시각적으로 조용하고
예측 가능해야 한다. `2.jpeg`의 절제된 업무 도구 분위기와 정보 계층은 참고하지만,
일반 채팅방·중앙 검색·그룹 기능을 표현하는 화면은 만들지 않는다.

## 시각 원칙

1. 장식보다 현재 상태와 다음 행동을 우선한다.
2. 색상은 상태를 보조할 뿐, 보안 검증의 근거가 되지 않는다.
3. 보안 경고는 작고 희미하게 만들지 않는다.
4. 잠금·삭제·초대·백업은 서로 다른 작업으로 시각적으로 분리한다.
5. 모든 화면은 제목, 현재 위치, 주요 행동, 실패 시 다음 행동을 가진다.
6. 기술 용어는 필요한 순간에만 설명과 함께 노출한다.

## 토큰 초안

```css
--color-canvas: #f4f4f2;
--color-surface: #ffffff;
--color-surface-muted: #ededeb;
--color-line: #d0d0cc;
--color-text: #1d1d1b;
--color-text-muted: #686864;
--color-text-subtle: #8b8b86;
--color-accent: #3f4548;
--color-accent-surface: #eff0ef;
--color-warning: #8a5b12;
--color-warning-surface: #fff7e5;
--color-danger: #a33e35;
--color-danger-surface: #fff0ee;
--radius-sm: 0;
--radius-md: 0;
--radius-lg: 0;
--shadow-panel: 0 1px 2px rgb(0 0 0 / 4%);
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-5: 24px;
--space-6: 32px;
```

토큰 값은 구현 중 조정할 수 있지만, 다음 제한은 유지한다.

- 페이지 배경에 radial/linear gradient를 사용하지 않는다.
- 상태가 아닌 장식 목적으로 초록·주황·빨강을 사용하지 않는다.
- 큰 제목은 시작 화면의 작업 제목에만 사용하고, 잠금 후에는 일반적인 업무 도구 크기로 낮춘다.
- 패널마다 강한 그림자를 넣지 않는다.
- 카드·버튼·입력·dialog는 각진 모서리(`border-radius: 0`)를 사용한다. 원형은 상태 점처럼
  원형 의미가 필요한 표시 요소에만 허용한다.
- pill은 세션 상태·검증 상태처럼 짧은 상태에만 사용한다.

## 레이아웃

### 잠금 전

최대 폭이 제한된 단일 작업 카드다. 프로필 선택/생성, 암호 문구, 백업 복구를 한 화면에
보여주되, 사용자가 동시에 여러 보안 작업을 수행하지 않도록 탭 또는 단계로 분리한다.

### 잠금 후 넓은 화면

```text
rail 220px | local list 280px | main minmax(0, 1fr)
```

- rail은 제품 위치와 전역 보안 동작만 담당한다.
- local list는 저장된 연결만 보여준다. 검색은 로컬 목록에만 적용한다.
- main은 선택된 상태 하나만 담당한다.

### 잠금 후 좁은 화면

rail과 local list를 동시에 고정하지 않는다. 현재 단계 하나를 보여주고 뒤로가기와
상단 제목으로 위치를 복원한다. 대화 입력은 화면 하단에서 가려지지 않아야 한다.

## 컴포넌트 규칙

### 버튼

- primary: 현재 단계의 유일한 주요 행동.
- secondary: 안전한 보조 행동.
- quiet: 화면 이동·취소·잠금.
- danger: 삭제·폐기. 항상 확인 단계를 가진다.
- disabled: 비활성 이유를 인접 텍스트로 설명한다.

### 상태

- `안전 확인 필요`: 주황 계열 + 전송 차단.
- `검증 완료`: 초록 계열 + 외부 채널 대조 완료라는 텍스트.
- `전송 불가`: 빨강 계열 + 수동 봉투 등 안전한 대체 행동.
- `잠금`: 중성 회색 + 잠금 해제 행동.

색상만으로 상태를 구분하지 않고 아이콘·레이블·설명을 함께 사용한다.

### 보안 자료

초대, fingerprint, 안전 문구, profile backup, session backup, transcript export는 각각
자료의 종류와 보관 주의를 제목에 포함한다. 자동 복사 버튼은 “복사됨”만 표시하지 않고,
전송 후 클립보드 기록과 동기화 기록을 지우라는 안내를 함께 표시한다.

### 메시지

메시지 bubble은 발신자 구분을 위한 최소한의 배경만 사용한다. 시간과 전달 상태는 작게
표시하되, 암호화 여부·안전 문구 검증 여부·identity 경고는 bubble 안에 숨기지 않고 대화
헤더 또는 별도 상태 영역에 둔다.

## 접근성 기준

- 모든 입력에 연결된 label과 오류 설명을 제공한다.
- 포커스 링을 제거하지 않는다.
- dialog가 열리면 첫 입력으로 포커스를 이동하고 취소 후 원래 버튼으로 돌린다.
- `aria-live`는 진행·실패·잠금 상태에만 사용한다.
- `prefers-reduced-motion`에서 애니메이션을 제거한다.
- 320px 폭에서 수평 스크롤 없이 주요 흐름을 완료한다.
- 키보드만으로 프로필 생성, 초대 입력, 안전 문구 확인, 메시지 전송, 잠금을 수행한다.
