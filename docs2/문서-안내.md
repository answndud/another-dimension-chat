## 현재 제품 기준

- 실행 경로: `apps/web`(React), `apps/daemon`, `apps/relay`, `apps/tools`
- 웹 UI: React 19 + TypeScript + Vite, WebSocket 실시간 수신
- 브라우저는 화면·입력만 담당하고 identity key, MLS state, database key를 소유하지 않는다
- relay는 opaque envelope·invite rendezvous(다중 response)·encrypted blob만 전달한다
- 그룹 채팅: batch add-member + 다중 welcome join 지원 (3인+ E2E smoke 통과)

실제 코드와 문서가 충돌하면 현재 코드를 우선한다.
