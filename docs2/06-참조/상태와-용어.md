# 상태와 용어

작성 기준: 2026-08-23 개편 완료 후 현재 코드 상태

## 계정·기기

| 용어 | 의미 |
|---|---|
| account root | 계정 신원을 대표하는 장기 서명 키 |
| device | 계정에 연결된 개별 실행 환경과 기기 키 |
| account ID | 공개키에서 파생된 암호학적 식별자 |
| device fingerprint | 기기 공개키를 사람이 비교할 수 있게 표현한 값 |
| profile passphrase | daemon 저장소 키를 보호하는 랜덤 비밀값 |

## 연결·암호화

| 용어 | 의미 |
|---|---|
| invite | 만료·서명·relay binding을 가진 일회성 연결 자료 |
| invite code | invite를 relay에서 한 번 소비하기 위한 사용자 입력값 |
| safety number | 양측 identity/device 공개키를 비교하는 검증 표현 |
| OpenMLS session | daemon이 소유하는 메시징 그룹 상태 (1:1 및 N인) |
| epoch | MLS 상태의 순서 세대. stale 입력은 적용하지 않음 |
| `ADENV1` | daemon 사이에 전달되는 opaque envelope 형식 표식 |
| batch add-member | 여러 key package를 한 번의 MLS commit으로 그룹에 추가 |
| welcome | 새 멤버가 MLS group에 join하기 위해 받는 자료 |

## relay·bridge

| 용어 | 의미 |
|---|---|
| relay | 암호문·초대·암호화 blob을 전달하는 사용자 운영 서비스 |
| capability | relay 작업 권한을 나타내는 bearer secret |
| inbox | opaque envelope를 TTL 동안 보관하는 전달 큐 |
| blob | 첨부파일의 암호화된 바이트 저장물 |
| receipt | relay가 특정 제출을 처리했다는 서명된 결과 |
| bootstrap URL | daemon local session을 처음 교환하기 위한 일회성 URL |
| local bridge | Chromium과 daemon 사이의 인증된 loopback HTTP 경계 |
| rendezvous | 초대 코드로 연결된 양측이 key-package/welcome을 교환하는 relay 경유지 |

## 실시간 레이어 (P2 신규)

| 용어 | 의미 |
|---|---|
| `/local-api/events` | daemon WebSocket endpoint. 인증된 클라이언트에게 push 이벤트 전송 |
| `messages_updated` | 새 메시지가 처리되었음을 알리는 broadcast payload |
| heartbeat ping | WebSocket 연결 유지를 위한 20초 주기 ping frame |
| reconnecting | WebSocket 끊김 후 재연결 시도 중 상태 (UI 배너 표시) |

## 사용자에게 보이는 상태

```text
초대
  created → consumed → paired
      ├── expired
      └── rejected

연락처
  pending → safety-unverified → verified
                         └──────→ blocked

메시지
  drafted → encrypted → submitted
                    ├─ received
                    ├─ stored
                    └─ failed / retryable

daemon
  stopped → bootstrapping → unlocked → locked
                         └────────────→ revoked

WebSocket (P2)
  connecting → online → reconnecting → online ...
                   └── offline
```

`submitted`는 relay가 받았다는 뜻이고, `received`는 상대 daemon이 가져갔다는 뜻이며,
`stored`는 상대 daemon의 local encrypted store에 기록됐다는 뜻이다.

## 오류 표현

| 표현 | 의미 | 기본 조치 |
|---|---|---|
| expired | 시간 제한이 끝남 | 새 invite/session 생성 |
| rejected | 검증·승인에서 거부됨 | 원인 확인 전 재전송하지 않음 |
| stale | 이전 epoch/state의 입력 | local state와 상대 기기 확인 |
| conflict | 같은 ID에 다른 bytes/state | 자동 덮어쓰기 금지 |
| retryable | 일시적인 전달·네트워크 실패 | 같은 bytes만 제한적으로 재시도 |
| revoked | 계정·기기·session이 폐기됨 | 새 신원 검증 |
| corrupt | 저장 데이터 형식·무결성 실패 | 원본 보존 후 recovery |
