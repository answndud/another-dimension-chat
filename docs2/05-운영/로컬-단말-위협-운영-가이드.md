# 로컬 단말 위협 운영 가이드

작성 기준: 2026-08-23 개편 완료 후 현재 코드 상태

이 문서는 Another Dimension이 실행되는 Mac 자체가 메시지의 보안 경계라는 사실을 설명한다.
앱의 암호화는 relay 운영자에게 평문을 숨기지만, 감염된 Mac·키로거·화면 캡처·악성 브라우저
확장·강제된 사용자 행동을 막아 주지 않는다.

## 사용 전

- 운영체제와 Chromium은 공식 업데이트 경로로 유지한다.
- 낯선 브라우저 확장, 원격 제어 도구, 키보드 입력 기록 도구를 제거하거나 사용을 중지한다.
- 화면 공유·녹화·회의·원격 지원을 시작한 상태에서는 메시지를 작성하지 않는다.
- 알림 미리보기, 클립보드 동기화가 민감한 대화 내용을 노출하지 않는지 확인한다.
- 복구 파일은 암호화된 오프라인 매체에 보관하고 화면 공유에 노출하지 않는다.

## 실행 중

- 대화 화면을 열어 둔 채로 화면을 공유하거나 자리를 비우지 않는다.
- 초대 코드, 안전번호, 일회성 화면 주소를 클립보드에 오래 두지 않는다.
- 예고하지 않은 UI, 반복적인 복호화 실패가 나오면 즉시 **잠그기**를 누르고 새 메시지를
  보내지 않는다.
- 안전번호가 바뀐 경우 상대방을 별도 신뢰 채널에서 다시 확인하기 전까지 승인하지 않는다.

## 단말이 의심될 때

악성코드, 키로거, 무단 원격제어가 의심되면 해당 Mac을 신뢰할 수 있는 통신 단말로 취급하지
않는다. 별도 신뢰 단말에서 상대방에게 상황을 알리고, 기존 연락처·기기·relay 자격을 회전하거나
폐기할 운영 절차를 결정한다. 이미 읽힌 화면·촬영된 화면은 회수할 수 없다.
