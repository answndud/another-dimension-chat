# 초보자를 위한 전체 설치·실행 가이드

작성 기준: 2026-08-23 · macOS (Apple Silicon) 기준

이 가이드는 **프로그래밍을 몰라도**, **Xcode나 개발 도구를 설치하지 않고도**,
Another Dimension Chat을 받아서 실행하고 암호화 메시지를 주고받을 수 있게 해준다.

> **핵심**: 사용자는 미리 빌드된 배포 패키지(`.tar.gz`)를 받아서 풀고 실행만 하면 된다.
> Rust 컴파일, Node.js, Xcode가 전혀 필요 없다.

---

## 준비물

| 필요한 것 | 설명 |
|---|---|
| Mac (Apple Silicon, M1 이상) | macOS 12 이상 |
| Chromium 계열 브라우저 | Chrome, Edge, Brave 등. Safari/Firefox는 미지원 |
| 디스크 여유 공간 | 50 MB 이하 (매우 작음) |

두 사람이 메시지를 주고받으려면 **Mac 두 대**가 필요하다.

---

## 1단계: 배포 패키지 받기

운영자 또는 개발자에게 다음 세 가지를 **별도 신뢰 채널**(전화, 대면 등)로 받는다.

| 받을 것 | 형태 |
|---|---|
| 배포 패키지 | `another-dimension-0.1.0.tar.gz` 파일 |
| 파일 무결성 확인용 | SHA-256 해시 값 |
| 서명 검증용 | release public key (PEM 파일) |

> ⚠️ 확인되지 않은 인터넷 파일이나 메신저로 전달된 실행 파일을 바로 열지 마세요.

## 2단계: 패키지 풀기

`Spotlight`(⌘ + Space)에서 **터미널**을 열고:

```sh
# 다운로드 폴더로 이동
cd ~/Downloads

# 압축 풀기 (파일명은 실제로 받은 것으로)
tar xzf another-dimension-0.1.0.tar.gz

# 생성된 폴더 확인
ls
# → another-dimension-0.1.0 이라는 폴더가 보이면 성공

# 사용하기 편리한 위치로 이동
mv another-dimension-0.1.0 ~/another-dimension
cd ~/another-dimension
```

## 3단계: 설치 (스크립트 한 번 실행)

```sh
./scripts/install_local_server.sh \
  --archive . \
  --public-key /path/to/release-public-key.pem
```

성공하면 다음과 같이 출력됩니다:

```
client 설치 완료: /Users/<이름>/.local/share/another-dimension/server
```

## 4단계: 앱 실행

### 방법 A — Finder에서 더블클릭 (가장 쉬움)

설치된 폴더 안에 있는 **Another Dimension.app**을 더블클릭한다.

### 방법 B — 터미널에서 실행

```sh
~/.local/share/another-dimension/server/scripts/installed_launcher.sh start
```

처음 실행하면 자동으로 relay + daemon이 시작되고 Chromium 화면이 열린다.

## 5단계: 프로필 만들기

Chromium에 Setup 화면이 나타난다.

1. **표시 이름** 입력 (예: `Alice`)
2. **프로필 만들기** 클릭
3. 복구 파일을 저장할 위치를 선택 → **암호화된 USB**에 저장

> ⚠️ 복구 파일 없이는 데이터 손상 시 계정 복구가 불가능하다.
> 일반 클라우드(Dropbox, Google Drive 등)에 저장하지 않는다.

저장 완료 후 대화 화면으로 이동하면 설정 끝!

## 6단계: 상대방과 연결하기

### 초대하는 쪽 (Alice)

대화 화면에서 **일회성 초대 만들기** 클릭 → 초대 코드(예: `ABCD-EFGH-...`)가 표시된다.
이 코드를 전화나 문자 등으로 상대방에게 전달한다.

### 참여하는 쪽 (Bob)

Bob의 Mac에서 같은 방법으로 앱을 실행하고 Setup을 마친 뒤,
받은 코드를 **초대 참여하기**에 붙여넣는다.

### 안전번호 대조 (양쪽 필수!)

양쪽 화면에 같은 안전번호가 표시된다. **전화나 대면**으로 번호가 같은지 확인한 후,
양쪽 모두 **안전번호 확인** → **승인**을 클릭한다.

### 대화 시작! 🎉

Alice 화면에 Bob 연락처가 나타난다. 클릭해서 메시지를 보내면 Bob 화면에 **실시간으로**
메시지가 나타난다.

## 7단계: 그룹 채팅 (3인 이상)

1:1 대화가 연결된 상태에서 **그룹 초대** 섹션에 다른 연락처 목록이 표시된다.

1. 추가할 멤버 체크박스 선택
2. **그룹에 추가** 클릭
3. 멤버가 welcome을 받으면 자동으로 그룹 합류

---

## 매일 사용하기

앱을 다시 열려면 **Another Dimension.app을 더블클릭**하거나:

```sh
~/.local/share/another-dimension/server/scripts/installed_launcher.sh start
```

새 메시지는 **자동으로** 화면에 나타난다. 새로고침 버튼을 누를 필요 없다.

상단 배너가 **"실시간 수신 대기 중"**이면 정상이다.

## 종료하기

- 사이드바 하단 **잠그기** 클릭 → 세션 잠김
- 완전히 종료하려면 터미널에서:

```sh
~/.local/share/another-dimension/server/scripts/installed_launcher.sh stop
```

---

## 문제 해결

| 증상 | 해결 |
|---|---|
| 앱이 열리지 않음 | macOS 보안 설정에서 "확인 없이 열기" 허용 |
| "연결 대기"만 표시 | relay가 실행 중인지 확인: launcher 재시작 |
| 실시간 배너 "재시도 중" | 자동 재연결 대기 (3초). 지속 시 daemon 재시작 |
| 메시지 전송 실패 `pairing_not_ready` | 안전번호 대조 후 승인했는지 확인 |
| 초대 코드 만료 | 새 초대 생성 (10분 유효) |
| 복호화 실패 반복 | **잠그기** 누르고 운영자에게 문의 |

## 보안 주의사항

| 하지 말아야 할 것 | 이유 |
|---|---|
| passphrase를 이메일·메신저로 전송 | 유출 시 계정 탈취 |
| 복구 파일을 클라우드에 저장 | 클라우드 해킹 시 복구 파일 노출 |
| 화면 공유 중 대화 내용 표시 | 상대방·녹화 프로그램이 읽을 수 있음 |
| `open once:` URL 재사용 | bootstrap secret 노출 |
| 알 수 없는 출처의 패키지 실행 | 변조된 바이너리일 가능성 |
