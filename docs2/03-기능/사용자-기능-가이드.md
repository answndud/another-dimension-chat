# 사용자 기능 가이드

작성 기준: 2026-08-23 개편 완료 후 현재 코드 상태

## 1. 화면 구성

앱을 실행하면 Chromium에 두 가지 화면 중 하나가 표시된다.

### Setup 화면 (최초 실행)

표시 이름을 입력하면 daemon이 로컬 계정과 기기 신원을 생성하고, 운영체제 난수로
프로필 암호문구를 생성해 화면에 표시한다. 이 암호문구를 화면에서 확인한 뒤 복구 파일을
암호화된 오프라인 매체에 저장해야 대화를 시작할 수 있다.

### Ready 화면 (일상 사용)

왼쪽 사이드바에 4개 view가 있다: **대화**, **기기**, **보안과 복구**, **상태**.
상단에 실시간 연결 상태 배너가 표시된다.

| 배너 상태 | 의미 |
|---|---|
| 실시간 수신 대기 중 | WebSocket이 연결됨. 새 메시지가 자동으로 표시됨 |
| 실시간 연결 재시도 중 | WebSocket이 끊김. 3초마다 재연결 시도 중 |
| 실시간 연결 준비 중 | WebSocket 연결 초기화 중 |

## 2. 초대와 연결

### 초대 만들기

대화 view에서 **일회성 초대 만들기**를 누르면 초대 코드가 생성된다. 이 코드는 10분 뒤
만료되고 한 번만 사용할 수 있다. 코드를 복사해 상대방에게 별도 신뢰 채널(전화, 대면 등)로
전달한다.

### 초대 참여하기

상대방에게 받은 초대 코드를 **초대 참여하기** 입력란에 붙여넣는다. daemon이 코드의
서명·만료·1회 사용 여부를 검증하고 상대 신원을 확인한다. 승인 전에는 연결되지 않는다.

### 안전번호 확인

양쪽이 같은 안전번호를 별도 신뢰 채널(전화, 대면)에서 대조한다. 번호가 일치하면
**승인**을 눌러 페어링을 확정한다. 번호가 일치하지 않으면 승인하지 말고 상대 신원을
재확인한다.

## 3. 메시지 보내기·받기

### 보내기

대화 입력란에 텍스트를 입력하고 **보내기** 버튼을 누르거나 `Ctrl+Enter`(macOS:
`Cmd+Enter`)를 누른다. daemon이 OpenMLS로 암호화한 뒤 relay에 제출하고, 전송 상태가
메시지 옆에 표시된다.

메시지 만료를 설정할 수 있다: 만료 없음, 1시간, 24시간, 7일.

### 받기 (실시간)

상대방이 메시지를 보내면 daemon의 maintenance tick(15초 이내)이 relay에서 가져와
복호화하고, WebSocket push로 브라우저에 즉시 알린다. 별도 새로고침이나 버튼 클릭 없이
메시지가 화면에 자동으로 나타난다.

WebSocket이 일시적으로 끊긴 경우에도 재연결 후 다음 sync에서 놓친 메시지를 자동으로
가져온다.

### 이전 대화 불러오기

**로컬 대화 기록 불러오기** 버튼으로 daemon의 암호화 저장소에서 최근 200개 메시지를
복구한다. **이전 대화 기록 더 불러오기**로 계속 과거를 탐색할 수 있다.

### 첨부파일

**파일 보내기**에서 파일을 선택하면 daemon이 64 KiB 청크 단위로 암호화해 relay blob에
올린다. 진행률이 표시되며, 수신자는 첨부파일 다운로드 버튼으로 복호화된 원본을 받을 수
있다. 최대 32 MiB.

## 4. 그룹 채팅 (P5 완료)

1:1 대화가 연결된 상태에서 **그룹 초대** 섹션에 연결된 연락처 목록이 표시된다.

1. 추가할 멤버의 체크박스를 선택한다.
2. **그룹에 추가**를 누른다.
3. daemon이 선택된 멤버들의 key package를 batch add-member로 MLS 그룹에 추가하고,
   각 멤버에게 welcome을 relay를 통해 전달한다.
4. 멤버가 welcome을 받으면 자동으로 그룹에 join되고, 이후 그룹 메시지를 주고받을 수
   있다.

## 5. 기기 관리

기기 view에서 현재 계정에 연결된 기기 목록과 기기 이벤트를 확인할 수 있다. 의심되는
기기는 **폐기** 버튼으로 제거하면 해당 기기의 세션이 즉시 무효화된다.

## 6. 보안과 복구

### 복구 파일

최초 설정 시 복구 파일을 저장해야 한다. 이 파일이 없으면 이 기기의 데이터가 손상되었을 때
계정을 복구할 수 없다. 암호화된 오프라인 매체(USB 등)에 보관한다.

### relay 신뢰

보안 view에서 현재 relay의 공개키 fingerprint와 신뢰 상태를 확인할 수 있다.

### 잠금·삭제

**잠그기**를 누르면 세션이 잠기고 새 요청이 거부된다. **데이터 삭제**는 로컬 프로필을
완전히 제거하며 복구 불가능하다.
