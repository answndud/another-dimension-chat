# 다운로드·설치·실행 가이드

작성 기준: 2026-08-23 개편 완료 후 현재 코드 상태

이 문서는 일반 사용자가 Mac에서 검증된 배포본을 받아 실행하고, 상대방과 첫 메시지를
보내기까지의 안내다. 내부 release manifest·Rust binary·data directory를 직접 다루는
운영자 절차는 이 문서의 사용자가 수행하지 않는다.

## 1. 받기 전에 확인할 것

운영자에게 다음 세 가지를 별도 신뢰 채널로 받는다.

- Mac용 Another Dimension Chat 배포 폴더 또는 압축 파일
- release 파일의 SHA-256
- release signing fingerprint

현재 공개 자동 다운로드 주소는 제공하지 않는다. 확인되지 않은 인터넷 파일이나 메신저로
전달된 실행 파일을 바로 열지 않는다.

## 2. 설치

1. 운영자가 전달한 압축 파일을 Mac의 `다운로드` 폴더에 저장한다.
2. 운영자가 안내한 파일명과 다운로드한 파일명이 같은지 확인한다.
3. 압축을 풀고 `Another Dimension.app`을 응용 프로그램 폴더로 옮긴다.

## 3. 최초 프로필 설정

1. `Another Dimension.app`을 더블클릭하면 Chromium 화면이 열리고 Setup 화면이 표시된다.
2. 표시 이름을 입력하고 **프로필 만들기**를 누른다.
3. daemon이 운영체제 난수로 프로필 암호문구를 생성해 화면에 표시한다.
4. **복구 파일 저장**을 눌러 파일을 암호화된 오프라인 매체(USB 등)에 저장한다.
   - 이 파일 없이는 데이터 손상 시 계정을 복구할 수 없다.
   - 일반 클라우드 폴더에 저장하지 않는다.
5. 저장이 완료되면 대화 화면으로 이동한다.

## 4. 상대방과 연결하기

### 초대하는 쪽

1. 대화 view에서 **일회성 초대 만들기**를 누른다.
2. 초대 코드를 복사해 상대방에게 전화나 대면 등 별도 신뢰 채널로 전달한다.
3. 상대방이 코드를 사용하면 자동으로 페어링 요청이 표시된다.

### 참여하는 쪽

1. 받은 코드를 **초대 참여하기**에 붙여넣고 버튼을 누른다.
2. 상대 신원이 확인되었다는 메시지가 표시되면 승인을 기다린다.

### 안전번호 대조 (양쪽)

1. 화면에 표시된 안전번호를 메모하거나 기억한다.
2. 상대방에게 전화하거나 만나서 서로의 번호가 같은지 확인한다.
3. 양쪽 모두 **안전번호 확인**을 누르고 **승인**을 누른다.
4. 대화 화면이 활성화되고 메시지를 주고받을 수 있다.

## 5. 그룹 대화 시작하기

1:1 대화가 연결되면 그룹 초대 섹션에서 다른 연락처를 선택해 그룹에 추가할 수 있다.
선택한 멤버들이 welcome을 받으면 자동으로 그룹에 합류한다.

## 6. 일상 사용

- 새 메시지는 실시간으로 자동 표시된다 (별도 새로고침 불필요).
- 상단 배너가 "실시간 수신 대기 중"이면 정상이다.
- 잠글 때는 사이드바 하단 **잠그기**를 누른다.
- 앱을 다시 열려면 `Another Dimension.app`을 더블클릭한다.

## 7. 문제가 생겼을 때

- 화면의 오류 문구만 운영자에게 전달한다. 암호문구·초대 코드·local URL·원본 로그를 보내지
  않는다.
- 반복적인 복호화 실패, 예상하지 못한 UI, relay 연결 실패가 계속되면 **잠그기**를 누르고
  새 메시지를 보내지 않는다.
- 복구가 필요하면 운영자의 안내에 따라 recovery import 절차를 진행한다.
